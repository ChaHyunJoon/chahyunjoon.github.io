## Overview

This project studies how to improve the reliability of tool calling in LLM agents by addressing the semantic-execution correctness gap. The focus is on developing an online learning framework that remains robust when semantic intent and executable behavior diverge.

## Project Details

- Period: October 2025 - December 2025
- Affiliation: Seoul National University
- Theme: Reliable tool calling for LLM agents

## Summary

The core goal is to build a more dependable decision process for agent tool use, especially in settings where correct semantic understanding does not always lead to correct execution. The project explores constraint-decomposed online learning to support safer and more reliable agent behavior.
