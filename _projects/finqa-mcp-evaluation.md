## Overview

This project investigates how an MCP-based architecture can improve the accuracy of answering FinQA benchmark questions through tool-augmented reasoning.

## Project Details

- Period: March 2025 - June 2025
- Affiliation: Seoul National University
- Current Result: Accuracy of 0.68 with several tools

## Summary

Using an MCP architecture, we designed a tool-driven workflow for handling FinQA question sets more accurately. The main objective was to increase answer reliability by combining multiple tools within a structured reasoning pipeline.
